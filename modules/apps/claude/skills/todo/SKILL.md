# todo — 素のリストを出す

リストは**読み物ではなく作業台**。装飾は脳の負荷であって情報ではない。

## 出力の形

```
1. 科目/領域
   □ 1.1 項目名                     0.5h ／ 9/13
   1.2 親項目（それ自体は作業でない）
       □ 1.2.1 子項目               2h ／ 超過
```

チェックボックス・項目名・右端に「時間／期限」。**以上。**

## 足さないもの

- 表・枠線・色つきブロック・サマリ box・アイコン
- 「まず訂正」「結論から言うと」の類の前置き
- 参照情報の付録（ポリシー表・根拠・除外理由）
- **指定された切り口以外の軸**。科目別を頼まれたら期限順表を勝手に付けない

足したくなったら、足さずに**先に訊く**。

## スコープ

既定は **いま〜次の締切まで**。それより先は訊かれたときだけ。
「全部」と言われたときだけ学期末まで出す。

## 根拠は別便

数値・ポリシー・計算過程は**リストに混ぜない**。訊かれたら別に出す。
リストに載せてよいのは「時間」と「期限」だけ。

## PDF にするとき

**先にテキストで出して確認を取る。** PDF は確認が済んでから刷る。
内容・粒度・スコープの食い違いはテキストの段階で潰す——刷り直しは高い。

確認が済んだら Chrome ヘッドレスで刷る。**資料ではなくリストを刷る。**

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf=out.pdf "file://$PWD/list.html"
```

CSS は最小限（フォント・サイズ・行間・インデント・改ページ）だけ。
**日本語の等幅フォントは入っていない**ので、空白で桁を揃えない。右端の揃えは
flex（`.r{display:flex} .t{flex:1} .m{white-space:nowrap}`）で取る。

## 削れと言われたら

期限で切る。**切った線を1行で言う**（例：「超過分＋9/15までを残した」）。
消した項目を列挙し直さない。
